## Approach

I built a responsive React landing page for Kidrove's AI & Robotics Summer Workshop with a cheerful education-focused visual style, clear sections, and mobile-friendly spacing. The page includes a hero section, workshop details, learning outcomes, FAQs, and a registration form with required field validation, loading state, and success/error feedback. On the backend, I created a simple Express.js server with a `POST /api/enquiry` endpoint that accepts name, email, and phone number, validates the submitted data, and stores successful enquiries in a local JSON file. I kept the implementation lightweight so the project can run with `npm start`, while organizing the frontend into reusable React components for readability and easier maintenance. The design focuses on clarity for parents and an engaging workshop feel for children.
